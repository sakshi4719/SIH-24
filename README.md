My contribution for the Smart India Hackathon 2024

###app_imagetoisl1.py###
Takes an image, reads the text in it using PaddleOCR and displays the corresponding ISL video stored in a media directory.
The system can handle only individual words or letters and retrieve the appropriate ISL video files for each.
Users can upload images via a POST request, and the server responds with detected text and corresponding ISL video paths.
